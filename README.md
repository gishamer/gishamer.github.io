# Flurin Gishamer’s website

Personal website for Flurin Gishamer, AI Czar at Open Systems.

Live site: https://www.gishamer.io/

## Content

- `index.md`: professional focus, selected work, writing, and contact.
- `speaking.md`: reusable speaker biographies, topics, and references.
- `agent-mesh-workshop-2026/`: workshop resources.
- `_config.yml`: site metadata and navigation.
- `_layouts/default.html`: page layout and social metadata.

## Local build

```sh
bundle install
bundle exec jekyll build
bundle exec jekyll serve
```

The site is published with GitHub Pages. Check the generated pages and links before pushing changes.
